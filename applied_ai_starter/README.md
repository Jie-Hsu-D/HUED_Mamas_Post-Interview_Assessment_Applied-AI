# HUED Mamas Applied AI Assessment Starter

This repository is a synthetic hiring exercise. It contains no HUED Mamas production scoring logic, health data, prompts, or proprietary templates.

Implement the candidate assessment using the supplied bounded input contract, safety contract, cases, and test harness. The explanation module intentionally begins as a stub.

## Run the baseline

```bash
python -m unittest discover -s tests -v
```

No external model or package is required. You may add a small dependency only when you justify it and preserve deterministic, offline verification.
